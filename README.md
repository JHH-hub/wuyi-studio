# 无衣 WUYI · 无限影像场

AI 影像艺术工作室的全屏交互网站。石墨黑、暖白与少量浅青柠，保留选定的线形图标，以 WUYI 英文字标搭配。HTML、CSS、JavaScript 独立，无框架、外部字体或 CDN 依赖。

## 预览

Windows 双击仓库根目录的 **预览网站.cmd**，会启动本地服务器并在默认浏览器打开网站。需要已安装 Python 3；保持命令窗口开启，结束时关闭窗口即可。脚本仅监听本机 127.0.0.1，会从 4178–4189 中选择空闲端口，不需要部署到公网。

也可运行 `python tools/preview.py`。通过 HTTP 预览，避免直接双击 `dist/index.html` 时 file 协议的 WebGL 纹理权限限制。本地文件模式会展示静态画面和预览说明；照片纹理上传失败时保留程序纹理，不将失败照片标记为可用。

## 浏览方式

- 原生 WebGL 三维影像场，画面有独立的前后位置、倾角、透视、深度遮挡、距离雾化和轻微弯曲。
- 中央主标题持续显示，拖动和穿行时也保留。
- 拖动游移，滚轮或双指前后穿行；Shift + 滚轮横向游移。
- 方向键游移，W / S 或 + / - 前后穿行，Home 归位，空格暂停，Enter 打开离中心最近的一帧。
- “另一种可能”切换随机种子并重新构图；URL 可指定数值种子，如 `?seed=261026`。
- 默认开场种子为 261026。闲置后镜头缓慢前行，每约八秒变换一张可见画面，通过颗粒显影过渡。暂停按钮停止持续运动与自动更新，仍可主动浏览。底部 Z 数字表示虚拟空间的镜头位置。
- 点击画面展开并保存 PNG；实验索引提供固定列表，关于无衣展示三张原团队照片。
- “开始共创”仅下载本地 TXT 简报，不上传表单。真实成员姓名及联系渠道尚未提供。

## 文件与内容替换

- `dist/index.html`：页面结构、导航、弹窗、SVG 图标。
- `dist/field.css`：全站布局、响应式、Logo 描线和过渡。
- `dist/spatial.css`：三维版的排版、持续居中标题、轻量控制栏和移动布局。
- `dist/space.js`：独立的原生 WebGL 渲染器、顶点/片元着色器、三维空间分块、投影拾取与纹理管理。
- `dist/field.js`：镜头交互、暂停、种子、画面预览和简报下载。
- `dist/generative.js`：可复现种子的三类程序纹理、图像绘制工具。
- `dist/field-content.js`：成员、影像地址、标题和占位说明。替换或增加图片时修改 `images` 的 `src`、`title`、`note`，竖幅可设置 `aspect`。数量会自动用于空间与索引。
- `dist/assets/experiments/`：五张 AI 生成 WebP 占位。`provenance.json` 记录初始素材，`prompts-v2.json` 记录新增两张素材的完整提示词、生成工具和原文件名。
- `dist/assets/member-*.webp`：用户提供的团队照片。未推测成员身份或职位。

## 占位与性能边界

五张超现实影像由内置 imagegen 预先生成，另外三类纹理由浏览器程序绘制。无限延展指空间与构图的持续变化，并非调用模型生成无限新内容。页面已标注占位与实验性质，未虚构客户案例、业绩或奖项。上线正式作品时应同步更新说明。

空间按深度与视锥裁剪，只提交可能可见的画面；布局缓存达到 1600 后清理至约 1100，图片共享纹理，使用 mipmap 缩小过滤。设备像素比上限为 1.5，触屏为 1.25；渲染限速为桌面 45、触屏 30 FPS，这不是所有设备的实测帧率。页面隐藏、弹窗稳定或暂停稳定后不持续绘制。尊重系统“减少动态”偏好，默认暂停持续运动与弯曲动画。无法使用 WebGL 时显示静态背景，索引、团队和表单仍可浏览。双指手势已实现，浏览器预览验证涵盖拖动、按钮和键盘，真机触控仍需后续设备确认。
